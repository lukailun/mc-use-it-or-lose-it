# 麦麦积分末班车 · Mc-Use-It-or-Lose-It

> 麦当劳积分有固定有效期，到期未用即自动失效扣除。这个 Skill 只做一件事：**计算当月即将失效的积分，帮你进行抽奖或者兑换操作。**

麦当劳程序员创意开发大赛参赛作品，基于麦当劳 MCP 构建。

---

## 它解决什么问题

麦当劳[《会员服务协议》](https://www.mcdonalds.com.cn/page/member-service-agreement)中有积分有效期的说明：当月（第 n 月）内获得的积分的有效期截止至获得积分当月起的第 n+12 月的最后一天的 24 点。也就是说，每个月月末都有一批积分清零。但大部分用户根本不知道：

- 自己这个月有多少积分即将过期
- 抽奖一次要多少积分、能不能覆盖掉过期的那部分
- 商城里有哪几件商品是真的还能兑的

等到发现时，积分已经清零。本 Skill 把「查积分 → 找出口 → 算最小消耗 → 确认执行」这条链路压缩成一次对话。

## 目标用户

- **高频麦当劳用户**：积分攒得多，但不清楚过期规则，长期被动损失
- **低频偶尔吃一次的用户**：积分零散，单次过期额度小，不值得专门研究，但适合顺手体检
- **想用积分换到实物周边的用户**：需要知道哪些商品当前真的在售

## 安装方法

### 1. 申请 MCP Token

访问 <https://open.mcd.cn/mcp>，手机号登录后在「控制台」激活并复制 MCP Token。

### 2. 配置连接器

在 WorkBuddy 左侧边栏「专家 · 技能 · 连接器」→「连接器」→ 右上角「自定义连接器」→「配置 MCP」，填入：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

> 记得把 `YOUR_MCP_TOKEN` 换成实际 Token。脱敏示例见 [`mcp-config.example.json`](./mcp-config.example.json)。

### 3. 载入 Skill

把本目录放入 WorkBuddy 技能目录（`~/.workbuddy/skills/`），或直接在对话中引用本项目的 `SKILL.md`。

## 使用示例

直接说需求即可，不需要记命令：

```
我这个月有多少积分要过期？
帮我把快过期的积分花掉
积分抽奖现在有什么奖品
积分能兑换什么
```

## 计算脚本

无第三方依赖，Python 3.8+ 即可运行：

```bash
# 可读文本输出
python3 scripts/points_planner.py --input examples/sample-input.json

# 机器可读
python3 scripts/points_planner.py --input examples/sample-input.json --format json
```

脚本只做计算，**不发起任何网络请求、不执行任何消耗动作**。

## 设计取向

市面上的积分工具大多在做"帮你花更多钱"——推荐套餐、凑单满减。这个工具刻意反过来：

- 本月无过期积分时，直接告诉你**无需操作**，不制造焦虑
- 只推荐**能覆盖过期积分的最小消耗**，不推荐更贵的商品
- 已过期积分明确标注为**既成损失**，不假装能挽回

## 关于名字

**Use It or Lose It** 是英文里描述「权益过期作废」的固定说法——用了就是你的，不用就归零。麦当劳积分「到期未用即自动失效扣除、不累计到次月」的规则，正是这句话的字面写照。

中文名「**麦麦积分末班车**」取的是同一意象的另一个角度：末班车开走之前必须上车。区别在于——错过末班车还有下一趟，错过积分清零就再也没有了。
